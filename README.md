# 🌍 GlobeTrotter

GlobeTrotter is a full-stack travel planning web application that helps users discover destinations, create and manage trips, organize itineraries, track budgets, and manage their travel profile.

The project uses a React frontend with a Django REST Framework backend and PostgreSQL database. Destination information and location images are retrieved through static JSON destination data.

---

## ✨ Features

### 🔐 Authentication

- User registration
- User login
- JWT-based authentication
- Access and refresh tokens
- Protected API endpoints
- User-specific trips

### 🏠 Dashboard

- Popular international destinations
- Destination search
- Search destinations by name, city, or country
- Destination images
- Budget filtering
- Trip overview
- Previous and upcoming trips

### 🌎 Destination Discovery

- Destination data retrieved through external APIs
- Geoapify Places API integration
- Location coordinates
- Country and city information
- External location images
- Search-based destination discovery
- International destinations rather than only nearby locations

### ✈️ Trip Management

Users can:

- Create trips
- View their trips
- View individual trips
- Edit trips
- Delete trips
- Set destination
- Set start and end dates
- Set total budget
- Add a cover image

### 🗓️ Itinerary

- Day-based itinerary
- Activities
- Activity times
- Activity categories
- Activity costs
- Search activities
- Filter activities
- Sort activities
- Day totals
- Trip budget overview
- Trip route overview

### 👤 Profile

- User profile information
- Profile statistics
- Upcoming trips
- Previous trips
- Trip budget information
- View individual trips
- Copy trip information
